# 4-Week Project Backend

This repository contains the backend for my Cold Chain Operations Portal project completed during my internship at Encon Pharma. It includes the JavaScript code for the AWS Lambda functions and the Terraform used to deploy the backend infrastructure.

The backend uses API Gateway, Lambda, DynamoDB, IAM, SNS, SQS, CloudWatch and API keys. It supports creating, viewing, updating and deleting cold-chain temperature readings, and automatically raises an alert when a reading falls outside the safe 2°C to 8°C range.
